# Privacy

Short version: the game stores your run in your own browser, and sends one small
anonymous message per act to the Weather Mind. Nothing is kept on a server, and
there is no account, no analytics and no advertising.

## What is stored, and where

`localStorage`, in your browser, on your device:

- `gust.garden.v1` — how many runs you have completed and which islands bloomed.
- `gust.journal.v1` — the keeper's book: one line per completed run (the day, the
  seeds that came home, the wind's bearing) and the keeper's name.

Clearing site data, or loading the game with `?reset=1`, removes both. Neither is
ever uploaded.

## What is sent

When an act ends, the client posts to `/api/mission`:

```json
{ "stage": 1, "landed": 4, "lost": 1, "time": 41.2, "air": 0.6, "previous": "…" }
```

- `stage` — which act just finished (0–3)
- `landed` / `lost` — how many seeds came home and how many were lost
- `time` — the length of the act in seconds
- `air` — the outgoing bearing of the wind, normalised 0–1
- `previous` — the name of the previous act's mission, so the next one can differ

That is the entire payload. It contains no identifier, no device information, no
position and nothing typed by the player. If the request fails or the endpoint is
missing (for example because you loaded the build from a static host), the game
uses its offline mission bank and carries on; `?offline=1` skips the request
entirely.

## The model

If the deployment has a `GEMINI_API_KEY`, the serverless function forwards the
payload above to Google's Gemini API and asks for a mission in a fixed JSON
schema. The key lives only in the server environment; it is never sent to, or
bundled with, the client. Google's handling of that request is governed by the
Gemini API terms.

## The server

`api/mission.ts` does not write anything to disk, does not log the payload, and
keeps no state between requests. There is no database and no session.

## AI-generated content

The ten voice lines in `public/voice/` are **AI-generated narration**: synthetic
speech produced for this project by a text-to-speech model, from a script written
for the game (en-GB voice, dry and precise, in the manner of the keeper's book).
They are not recordings of a human speaker.

All other content in the game is procedural: the room, the diorama, the weather,
the ink in the ledger, the music and the sound effects are generated by code in
this repository. The mission text written by Gemini at run time is labelled as
such by the API (`source: "gemini"`, as opposed to `"fallback"`) and is never
shown as text in the headset — the world acts it out.
